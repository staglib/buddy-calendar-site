Buddy — personal calendar assistant

A private, single-user tool.

Buddy is a private, single-user personal assistant that runs on its owner's own computer. It connects to Google Calendar with the owner's explicit consent in order to read the owner's calendars and to add, edit, or delete events the owner asks for.

Buddy is not a public service. There are no other users, no sign-up, and no data collection beyond the Google Calendar API calls the owner initiates.
